## Learning Path

A practical progression is:

1. Start with **Drift Detector** and **Drip and Navigate** for discovery and navigation.
2. Continue with **Drip Login Lab** and **Drip Key SSH** for access and SSH-focused concepts.
3. Explore **Hidden Clues in HTML** and **Bluesource Code** for web investigation.
4. Study **Filter the Fuzz** for fuzzing-related discovery.
5. Move into Linux security with **Kernel Clues: Sudo to Root**.
6. Continue through **Blueshift Escalation** and **Drip to Root**.
7. Finish with **Polkit Pivot: From Foothold to Root** for the Polkit escalation theme.

## How to Use the Labs

1. Open each lab through its direct Learn SecByte link.
2. Review the scope and instructions before beginning.
3. Perform all activities only in authorized lab environments.
4. Record important observations, discovered clues, source-code findings, and configuration details.
5. Treat privilege-escalation exercises as controlled educational practice.
6. Focus on understanding the underlying security concepts.
